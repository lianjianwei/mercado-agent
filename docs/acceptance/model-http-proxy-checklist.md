## 真实网络烟测

目标地址：`https://api.86gamestore.com/v1/models`。测试请求未携带 API Key，未保存或输出任何密钥与响应正文。

| 路线 | 次数 | HTTP 结果 | 结论 |
| --- | ---: | --- | --- |
| 当前网络直连 | 3 | 451、451、451 | 服务拒绝当前网络地区访问。 |
| 本机 HTTP 代理 `127.0.0.1:7890` | 3 | 401、401、401 | 三次均到达服务认证层；未带 API Key，401 符合预期。 |

以上结果确认此前“偶尔成功、大部分失败”的主要因素是网络出口差异；通过本机 HTTP 代理后，请求能够稳定到达模型服务。401 不代表代理失败，只表示本次安全烟测刻意未提交 API Key。
