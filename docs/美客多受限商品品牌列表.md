## Agent 侵权风险判定规则

> 本节是美客多 Agent 的业务规则，不是官方品牌列表原文。风险结果只作提示和标记，不自动阻止编辑或发布。

### 判定顺序

1. 先判断待售商品是“品牌本体商品”，还是“第三方兼容配件”。
2. 如果卖的是上述受限品牌的本体商品，且用户无授权，标记为 **高风险**。
3. 如果卖的是第三方通用配件，受限品牌名只用于说明兼容对象，不因命中品牌列表直接判为高风险；满足下述条件时可判为 **不侵权**，证据不充分时标记为低或中风险并提示人工复核。
4. 未命中本列表的商品，由 AI 结合标题、主图和其他参考图判定为不侵权、低风险或中风险；如果发现明显仿冒、盗版角色、未授权 Logo 或其他强侵权证据，仍可标记为高风险。

### 兼容配件例外条件

以“适用于拓竹/Bambu Lab 打印机的第三方配件”为例，需同时检查：

- 待售商品确实是配件，而不是品牌打印机本体或仿冒主机。
- 标题和描述明确使用“适用于”、“兼容”、`for` 或 `compatible with`，不把受限品牌声称为配件自身品牌。
- 商品品牌字段填写配件的真实生产商；无品牌时按当前业务规则填写 `Generic`。
- 商品、包装和图片中不得出现伪造的品牌 Logo，也不得营造“官方原装”或“品牌授权”的误解。
- 不使用“仿品”、“复刻”、“同款”、“一模一样”等暗示仿冒的表述。
- 如果主图或配件外观上存在受保护的 Logo、角色、独特外观或专利设计，即使标题写了“兼容”，也需要提高风险等级。

美客多官方的[兼容配件刊登指引](https://global-selling.mercadolibre.com/learning-center/news/how-can-i-list-without-infringing-intellectual-property?guideKeyId=GE24&moduleKeyId=MO37) 也要求在标题中清楚表达“适用于/兼容”关系，并正确填写配件自身的品牌。

## 本地数据维护建议

- App 默认从这份本地快照读取品牌，不在每次侵权检测时请求官方网页。
- 匹配时忽略大小写，同时处理别名和括号中的名称，例如 `AP` / `Audemars Piguet`、`CALVIN KLEIN` / `CK`、`YVES SAINT LAURENT` / `YSL`。
- 官方列表可能调整，后续应提供“手动更新品牌快照”功能，并记录更新日期和数量变化。
