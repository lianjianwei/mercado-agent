# Mercado Agent 桌面应用设计规格

日期：2026-08-26  
状态：待用户最终审阅  
目标平台：macOS、Windows

## 1. 产品目标

Mercado Agent 是一个纯本地 Electron 桌面应用，对接妙手 ERP 的 Mercadolibre 采集箱，帮助用户完成三个彼此分离的核心流程：

1. 侵权检测：先分析妙手中的原始商品，生成风险等级、证据和提示，但不自动阻止用户继续操作。
2. 产品编辑：使用可切换的大模型生成和补全标题、描述、属性、SKU、包裹数据、净收益与商品图片，并保存回妙手。
3. 产品发布：由用户单独发起发布，跟踪妙手异步发布队列，只有确认商品进入 `published` 状态才判定成功。

应用不负责 1688 选品和采集。用户仍通过妙手浏览器插件将商品采集到妙手，并在妙手中先删除不需要的 SKU、修正明显错误类目、调整货源价格和选择参考图。

## 2. 首版范围

### 2.1 包含

- 纯本地 Electron 应用，无服务端依赖。
- macOS 和 Windows 安装包。
- 妙手单套 App Key / App Secret 配置。
- 文本与多模态模型：豆包、DeepSeek、OpenAI；可保存多套配置并快速切换启用项。
- 生图模型：豆包、OpenAI；与文本模型独立配置，支持文生图和图生图。
- 七牛云 Access Key、Secret Key、Bucket、域名配置。
- SQLite 文件数据库，使用 Node 内置 `node:sqlite`，通过 Repository 层隔离持久化逻辑。
- 侵权检测、产品编辑、图片处理、产品发布、任务记录和配置管理。
- 图片压缩、格式转换、七牛云上传和网络 URL 保存。
- 单个与批量处理。

### 2.2 不包含

- 1688 自动选品和自动采集。
- 服装尺码表；服装类目只做过滤提示。
- 云端账号、远程数据库、多用户协作和跨设备同步。
- 后台服务器、Web 控制台或移动端。
- 自动绕过侵权、类目、重量、尺寸等人工风险确认。
- 妙手没有开放的“发布失败记录”自动读取能力。

## 3. 视觉与导航

采用已确认的 A「专业列表工作台」：深海蓝左侧导航、白色高密度数据区、黄色品牌识别点、蓝色主要操作按钮。该风格优先保证长时间操作时的可读性和商品数据密度。

左侧一级导航：

- 工作台
- 侵权检测
- 产品编辑
- 产品发布
- 任务记录
- 模型与凭证
- 帮助与诊断

所有危险、争议和失败状态必须同时使用颜色、文字和图标，不得仅通过颜色表达。

## 4. 工作台

工作台默认查询妙手 `notPublished` 商品，不将已发布商品混入日常处理列表。

顶部状态切换：

- 未发布
- 定时发布
- 已发布历史
- 全部记录

主表按商品展示，一行代表一个采集箱商品，SKU 在完整编辑页展开。表格包含商品、目标站点、SKU 数量、侵权状态、编辑状态、提示和最近同步时间。

右侧快速检查区展示选中商品的最新有效侵权结果、编辑完整度、类目争议、重量尺寸争议和图片问题。单击商品显示概要，双击或使用按钮进入完整编辑页。

批量操作包括侵权检测、AI 编辑和发布。批量发布只接受已经通过发布前检查的商品。

## 5. 商品生命周期与妙手状态

妙手采集箱状态：

- `notPublished`：未发布，可进入侵权检测和产品编辑。
- `timingPublish`：定时发布，进入发布跟踪区，默认只读。
- `published`：已发布，进入历史档案，默认只读。

本地记录不得因为商品不再出现在某个妙手查询结果中而删除。如果商品从 `notPublished` 消失，应用必须继续查询 `timingPublish` 和 `published`；三个状态都找不到时标记为“妙手中未找到”，保留最后本地快照并等待人工确认。

已发布历史保存侵权检测版本、AI 编辑版本、最终保存快照、发布尝试和站点结果。妙手无法返回详情时显示本地最后快照及最后同步时间。

## 6. 侵权检测

### 6.1 检测输入

- 原始标题与描述
- 品牌、型号、类目及相关属性
- SKU 名称
- 主图和参考图
- 服装类目识别结果

### 6.2 风险等级

- 无侵权
- 低风险
- 中风险
- 高风险

本地受限品牌快照中的品牌本体商品默认高风险。未命中列表的商品由 AI 结合文本和图片判断。检测结果只提示，不自动阻止编辑或发布。

### 6.3 兼容配件例外

先判断待售商品是品牌本体还是第三方兼容配件。品牌名称仅用于说明适用对象、商品品牌为真实制造商或 `Generic`、图片不含伪造 Logo、标题不暗示官方授权时，不因命中品牌词直接判为高风险。存在 Logo、仿冒外观、误导包装或受保护设计时提高风险等级。

### 6.4 快照与复检

每次检测保存不可变快照、内容指纹、模型配置、风险等级、证据和时间。

首次检测生成 V1。标题、描述、品牌、类目、相关属性、SKU 名称或图片变化时，V1 标记为“已过期”，但永久保留。价格、库存、净收益、重量和尺寸变化不导致侵权结果过期。

AI 编辑保存到妙手成功后自动对实际回读内容执行复检，生成 V2。最新完成且内容指纹一致的版本才是当前有效结果。历史页面支持查看 V1、V2 和差异。

## 7. 产品编辑

待编辑队列只显示 `notPublished` 且未进入发布队列的商品。已经进入妙手发布队列的商品暂时只读；确认失败后重新回到可编辑状态。

编辑页包含：

- 基础信息
- 类目与属性
- SKU 与定价
- 图片
- AI 变更记录

AI 先生成本地草稿，用户可以逐项修改。只有用户触发“保存到妙手”才写入妙手。保存成功后立即重新获取详情进行字段回读校验，再触发侵权复检。

### 7.1 标题与描述

妙手接口包含必填主标题 `title` 和可选站点标题 `siteAndTitleList`。界面显示：

- 商品主标题：西班牙语，所有站点的回退值。
- 站点标题覆盖：MX 西班牙语、AR 西班牙语、BR 葡萄牙语。

保存后回读 `siteAndTitleList`。如果妙手没有保留站点标题，界面明确标记“不支持站点标题覆盖”，发布时全部使用西班牙语主标题。发布接口只接受 `detailIds`，因此任何最终发布内容都必须先保存到妙手，不能仅保存在 Agent 本地等待发布时注入。

描述仅支持一份时使用西班牙语。标题必须控制在 60 字符以内；发布配置仍启用超长截断作为兜底。

### 7.2 类目与属性

- 类目优先读取妙手推荐结果。
- 类目不确定时显示置信度、候选类目和人工确认标记。
- 品牌统一填写 `Generic`。
- 型号必填。
- 根据类目属性规则填写必填属性；确定的可选属性尽量填写，不确定的留空并提示。
- 服装类目显示过滤提示，不进入尺码表流程。

### 7.3 SKU、包裹与净收益

- 保留用户在妙手中预先筛选后的 SKU。
- 默认显示库存为 5；库存不足或被用户移除的 SKU 不启用。
- 货源价格由用户预先加入运费，Agent 不擅自重算。
- 根据原始文本和参考图估算长宽高与重量，所有估算字段带来源、置信度和争议标记。
- 同时计算实际重量和体积重，取计费规则要求的最终计费重量。
- 最终计费重量或抛重超过 3000g 时标记不可推荐发布，但仍允许用户人工处理。
- 多 SKU 使用 SKU 净收益；全球净收益自动取所有启用 SKU 的最高值。
- 同一 SKU 在各站点使用相同 USD 净收益。
- 净收益大于 3 USD 时 MX/BR 默认铂金，否则默认经典；AR 永远经典。

具体净收益公式由用户后续提供，通过独立策略接口实现，不硬编码在 UI 或妙手适配器中。

## 8. 图片工作区

原始标题、描述、SKU 参考图和用户选中的妙手原图作为图生图输入。不得在没有参考图的情况下生成最终电商商品图。

- 每个启用 SKU 至少有一张独立主图，颜色或型号必须与该 SKU 一致。
- 多 SKU 共用一组详情图。
- 主图纯白背景，仅显示商品，无明显 Logo、文本或水印。
- 详情图展示尺寸、包装内容、功能和必要安装步骤。
- 所有图片至少 800×800，数量通常为 5 至 6 张，最多 10 张。
- 详情图文本优先同时使用西班牙语和葡萄牙语；放不下时仅使用西班牙语。
- 支持重新生成、局部重绘、顺序调整、删除、下载和设置主图。
- 上传前检查尺寸、数量、主图白底、文本、Logo、水印和 SKU 一致性。
- 生成原图压缩后上传七牛云，保存可公开访问的 URL 到妙手。
- 保存成功后使用妙手回读的最终图片列表执行侵权复检。

## 9. 发布前检查与提交

编辑和发布是两个独立功能。AI 编辑完成后只保存到妙手，不自动发布。

发布前检查：

- 最新侵权复检是否有效；风险只提示，不强制阻止。
- 类目与必填属性是否完整。
- SKU、库存、净收益和刊登类型是否完整。
- 包裹数据是否超过限制或存在未确认争议。
- 图片是否已上传并通过规则检查。
- 站点标题是否成功保存到妙手。

发布设置：产品预设模式、立即发布、关闭妙手自动翻译、标题超过 60 字符时截断。

## 10. 异步发布队列

发布接口返回 `success` 只表示妙手接收任务，不表示发布成功。每次提交建立独立发布尝试记录。

本地发布状态：

- 待提交
- 提交中
- 提交失败：发布接口立即返回错误。
- 妙手队列中：接口返回成功，等待妙手执行。
- 可能发布失败：提交满 1 小时后仍为 `notPublished`。
- 已确认失败：用户在妙手确认失败，并可填写失败原因。
- 发布成功：明确在 `published` 查询结果中找到。
- 状态未知：三个妙手状态都找不到。
- 已放弃：用户停止追踪该次尝试。

应用运行时定期轮询未完成任务；应用关闭后不承诺后台运行，重新启动时继续追踪。1 小时内始终显示“妙手队列中”，不得提前推断失败。超过 1 小时仍未发布只能显示“可能失败”，不能声称确定失败。

妙手当前开放文档没有发布任务结果或失败记录查询接口。首版提供“打开妙手检查”“我已确认失败”和失败原因备注。后续如果妙手开放接口，只替换状态来源，不改变本地状态模型。

## 11. 配置界面

所有配置均无默认凭证，必须由用户自行填写。首版明文保存到本地 SQLite，并允许查看、复制、编辑、测试连接和删除。

配置分组：

- 文本/多模态模型配置：提供商、配置名称、API Key、Base URL、模型名、启用状态。
- 生图模型配置：提供商、配置名称、API Key、Base URL、模型名、启用状态。
- 妙手：App Key、App Secret、Base URL、连接测试。
- 七牛云：Access Key、Secret Key、Bucket、公开域名、区域、连接与上传测试。

文本和生图配置相互独立。每组可保存多套配置，但同一用途只有一个当前启用项。界面必须清晰提示凭证当前为本地明文存储。

## 12. 本地数据设计

Repository 层隔离 SQLite，避免 UI、妙手接口和模型适配器直接编写 SQL。建议实体：

- `products`：妙手商品身份、当前妙手状态、生命周期和最后同步时间。
- `product_snapshots`：妙手原始、AI 草稿、保存后回读和发布时快照。
- `infringement_runs`：检测版本、内容指纹、模型、风险和证据。
- `edit_sessions`：AI 生成任务、字段变更、警告和保存结果。
- `image_assets`：参考图、生成图、压缩结果、七牛 URL、SKU 归属和规则检查。
- `publish_attempts`：每次提交、计时、轮询和最终状态。
- `publish_events`：发布时间线事件。
- `provider_configs`：模型配置。
- `app_credentials`：妙手和七牛凭证。
- `app_settings`：当前启用模型、轮询设置和 UI 偏好。

迁移脚本集中管理。Repository 对外使用领域对象，避免依赖 SQLite 特有 SQL，以降低未来迁移到 MySQL 或 PostgreSQL 的成本。

## 13. 适配器边界

- `MiaoshouRepository`：列表、详情、类目规则、保存与发布提交。
- `TextModelProvider`：文本与多模态输入、结构化输出。
- `ImageModelProvider`：文生图、图生图和局部重绘。
- `ObjectStorageProvider`：上传、URL 生成和连接测试。
- `ImageProcessor`：尺寸检测、压缩、格式转换和质量检查。
- `InfringementEngine`：本地品牌规则、兼容配件规则、AI 分析和证据标准化。
- `PublishTracker`：发布状态机、轮询、1 小时阈值和恢复追踪。

妙手提供的三个 Skill 作为接口行为和校验逻辑参考，不作为桌面应用运行时依赖。正式应用直接调用妙手开放 API。

## 14. 错误处理

- 任何批量任务都显示逐商品进度、成功、跳过和失败数量。
- 单个商品失败不终止整个批次。
- 模型输出必须先通过结构校验，失败时保留原内容并允许重试。
- 保存妙手后必须回读验证；不一致时显示字段级差异。
- 七牛上传失败保留本地压缩结果，允许单独重试上传。
- 发布追踪不得把超时或查询异常错误地标记为成功或确定失败。
- App 崩溃或重启后从 SQLite 恢复未完成的编辑、图片和发布任务。

## 15. 真实账号验证项

开始完整编码前后必须用测试商品验证：

1. `siteAndTitleList` 是否能保存、回读并在三个站点最终生效。
2. 妙手是否接受七牛云公开图片 URL，以及图片 URL 的格式限制。
3. 发布任务执行中商品在 `notPublished`、`timingPublish` 和 `published` 之间的真实变化。
4. 发布失败后商品字段、备注或列表响应中是否存在可利用的失败信号。
5. 已发布商品是否仍可通过详情接口读取完整内容。
6. 类目必填属性和单品/多 SKU 规则是否与接口文档一致。
7. 图片列表、SKU 图片和共用详情图保存后的真实结构。

这些验证失败时应用必须降级并清晰提示，不得静默假设妙手行为。

## 16. 验收标准

- 用户能配置并测试模型、妙手和七牛云连接。
- 用户能同步未发布商品并查看历史状态，不因妙手状态变化丢失本地数据。
- 侵权检测保存版本化快照，兼容配件不会因品牌词直接判高风险。
- AI 编辑能生成多语言内容、属性、SKU、包裹数据、定价和图片，并在保存妙手后回读验证。
- 商品图片符合主图、尺寸、SKU 区分、压缩和七牛云上传规则。
- 编辑不会自动发布；发布必须由用户单独确认。
- 发布接口成功后进入队列状态，1 小时内不判失败，只有命中 `published` 才判成功。
- 所有高风险和不确定结果均可人工复核并保留历史。
- macOS 和 Windows 安装包能够在没有服务端的情况下运行。
